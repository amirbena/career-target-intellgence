# Conversation Starters

The same starters as [`claude/conversation-starters.md`](../conversation-starters.md),
reused here without alteration, plus one additional starter for verifying
a fresh external install before relying on it for real research.

- "Here is my resume. Build my candidate profile."
- "Find 30 product companies within my commute limit."
- "Find recruiters at the top five companies."
- "Find engineering managers relevant to my background."
- "Verify who posted relevant jobs during the last 90 days."
- "Explain why this company is Priority 2."
- "Build my outreach queue."
- "Continue from this Research State file."

## Verification starter

Use this one first, right after installation, before any real research:

- "Confirm that the Career Targeting Intelligence Skill is available,
  summarize the active Project context, and explain which workflow module
  you would use for a resume-analysis request. Do not perform research
  yet."

See [`verification-guide.md`](verification-guide.md) for the full set of
smoke tests this starter is part of.
