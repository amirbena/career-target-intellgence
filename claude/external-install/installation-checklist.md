# Installation Checklist

Work through each section in order. Every step happens inside your own
Claude account — nothing here requires access to anyone else's Project.

## 1. Install the Skill ZIP

- [ ] Locate `skill/career-targeting-intelligence.skill.zip` inside the kit.
- [ ] Upload it as a Skill in your Claude account (or the surface you're
      installing into), following that surface's own Skill-installation
      flow.
- [ ] Confirm the installed Skill is named `career-targeting-intelligence`.

## 2. Create a private Project

- [ ] Create a new Claude Project you control.
- [ ] Keep it private unless you specifically intend to share it — sharing
      is a separate, deliberate choice (see
      [`privacy-guide.md`](privacy-guide.md)).
- [ ] Confirm the installed Skill from step 1 is available to this Project.

## 3. Paste the Project Instructions

- [ ] Open `project-instructions.md` from the kit.
- [ ] Paste its contents into the Project's instructions field, unedited.
- [ ] This file is copied from the repository's canonical compact
      instructions at packaging time — do not maintain a separate edited
      copy if you want to stay aligned with future kit updates.

## 4. Add the approved Knowledge

- [ ] Upload every file under `knowledge/` in the kit to the Project's
      Knowledge.
- [ ] Confirm the file count matches
      [`knowledge-files.md`](knowledge-files.md) — the allowlist is fixed
      and intentionally excludes personal data and Skill-source
      duplication.

## 5. Keep personal files private

- [ ] Do not upload your resume, real company lists, or real outreach
      history to any shared or team Knowledge — only to your own private
      Project, and only if you intend it to stay private.
- [ ] If you ever share this Project with others, review its Knowledge
      first and remove anything personal before sharing.

## 6. Run setup verification

- [ ] Open [`verification-guide.md`](verification-guide.md) and run its
      five smoke tests.
- [ ] Confirm each test behaves as documented before relying on the
      Project for real research.

Once every box above is checked, you're ready to use the product — start
from [`conversation-starters.md`](conversation-starters.md) or describe
your own background directly.
