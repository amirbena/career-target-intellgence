# Plugin Configuration

The values that configure the Career Targeting Intelligence ChatGPT
Plugin. The source of truth is [`plugin/plugin.json`](plugin/plugin.json)
(manifest and listing metadata) and [`plugin/SKILL.md`](plugin/SKILL.md)
(behavior); this document explains the choices. Format reference:
OpenAI's "Package your plugin" and plugin submission documentation.

## Format

A portable, skills-only plugin:

- `plugin.json` at the plugin root (the archive root).
- `skills/career-targeting-intelligence/SKILL.md` — behavior, routing,
  trust boundaries, output policy, and non-actions.
- `skills/career-targeting-intelligence/references/` — the nine generated
  reference bundles plus `capability-policy.md`.

OpenAI-specific listing fields live under `extensions.com.openai.interface`
in `plugin.json`.

## Unconfirmed choices

OpenAI's documentation does not pin down two choices in this package.
Verify both on the first dashboard upload and adjust if it is rejected:

- **Archive root:** `plugin.json` sits at the top level of the zip, with
  no wrapping directory. The docs say only to zip the plugin folder.
- **`interface.category`:** `Productivity` is a best-fit value; the
  accepted category list is not documented in the pages this package was
  built from.

## Manifest limits (enforced by `validate-chatgpt-plugin`)

| Field | Limit |
|---|---|
| `name` | required, ≤ 64 chars, lowercase letters, numbers, single hyphens |
| `version` | explicit semantic version |
| `description` | ≤ 4000 chars |
| `interface.displayName` | required, ≤ 30 chars |
| `interface.shortDescription` | required, ≤ 30 chars |
| `interface.longDescription` | required, ≤ 4000 chars |
| `interface.developerName` | required, ≤ 80 chars |
| `interface.defaultPrompt` | ≤ 3 unique prompts, ≤ 128 chars each, no app @mentions |

The documentation specifies no length limit for `SKILL.md` or its
reference files. `SKILL.md` frontmatter requires `name` (matching the
manifest) and `description`.

## Default prompts

The three `defaultPrompt` entries replace the former conversation
starters. They contain no real user data.

## Not configured

- **Apps (`.app.json`)** — not configured; submission with app references
  is not currently accepted.
- **MCP servers (`mcp.json`)** — not configured.
- **Lifecycle hooks** — not configured; hooks make a plugin ineligible
  for the public directory.
- **External APIs and credentials** — none.

## Plugin icon brief

Not generated by this repository. For whoever creates it (PNG, JPEG,
WebP, or SVG; square, at least 48×48 px, up to 5 MiB):

- Professional and clean.
- Research / intelligence theme (for example, an abstract map, network, or
  magnifying-glass motif).
- No company logos.
- No misleading affiliation with any company, job board, or platform.
